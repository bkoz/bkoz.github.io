Web Applications

A collection of web-based tools and applications I've developed.

Audio Stream Player

An advanced HTML5 audio stream player featuring real-time audio analysis and visualization. This application includes VU meters for monitoring audio levels, codec detection to identify the audio format, and comprehensive metadata extraction to display track information.

Features:

  • Real-time audio visualization with VU meters
  • Automatic codec detection and display
  • Metadata extraction and presentation
  • Clean, intuitive user interface
  • Support for multiple streaming formats

KNKX Streaming Player

A dedicated streaming audio player designed for KNKX radio. This player provides a seamless listening experience for KNKX's high-quality audio streams with an easy-to-use interface.

Features:

  • Optimized for KNKX radio streaming
  • HLS (HTTP Live Streaming) support
  • Responsive design for all devices
  • Simple playback controls

Album Artwork Tool

A web-based tool for browsing and managing album artwork from your music library. This application interfaces with iTunes/Apple Music to display album covers and associated metadata.

Features:

  • Browse album artwork from your music library
  • View high-resolution album covers
  • Display album and artist information
  • Clean, gallery-style interface
